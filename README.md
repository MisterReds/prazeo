# Prazeo

Платформа продажи билетов и управления мероприятиями. Текущий репозиторий содержит начальную продуктовую и техническую спецификацию.

- [EventPackage JSON Schema](schemas/event-package.schema.json)

## Архитектурное направление

Для первой версии предлагается модульный монолит на TypeScript с Next.js, NestJS/Fastify и PostgreSQL, отдельными фоновыми workers, hosted checkout и строгим версионированным импортом. PostgreSQL является источником истины для мест, резервов, заказов, платежных событий и аудита.

Импорт ИИ всегда создаёт проверяемый черновик. ИИ не публикует мероприятия, не меняет права и не записывает статусы продажи/резерва напрямую.

## Статус

Документация является проектной основой, не реализацией приложения и не подтверждением соответствия стандартам безопасности. Перед запуском нужно утвердить рынки, юридическую модель, платежного провайдера, налоги, правила возврата, нагрузку и эксплуатационные цели.
